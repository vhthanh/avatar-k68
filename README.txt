# Website tạo Avatar K68 - Trường Đại học Quảng Bình

## Cách chạy
- Mở `index.html` bằng trình duyệt để thử ngay trên máy tính.
- Để sinh viên truy cập bằng điện thoại qua Internet, tải toàn bộ thư mục này lên một dịch vụ hosting tĩnh như GitHub Pages, Netlify hoặc Cloudflare Pages.

## Cách sử dụng
1. Sinh viên mở trang.
2. Nhấn "Chọn ảnh cá nhân".
3. Ảnh được ghép tự động với khung K68.
4. Có thể kéo ảnh/căn chỉnh và nhấn "TẢI ẢNH ĐẠI DIỆN".
5. Dùng file PNG tải về làm ảnh đại diện Facebook.

## Quyền riêng tư
Không có máy chủ xử lý ảnh. Ảnh được đọc và ghép trực tiếp trong trình duyệt trên thiết bị của người dùng.

## Lưu ý
File khung `khung-k68.png` là chính file khung người dùng đã cung cấp.
